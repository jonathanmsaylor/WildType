# Visible inheritance — Editor evidence

These unedited 1920×1080 PNGs were captured from the running Unity Game view on 2026-09-24. They are documentation, not runtime game assets.

The temporary Editor-only verification fixture arranged existing founders, disabled AI movement, initiated normal eligible two-parent mating, supplemented food and accelerated juvenile growth. It never altered the resulting genomes or mutation probabilities. Nameplates/captions and the comparison camera were test-only aids. The fixture was removed before delivery.

1. **01-founders.png:** three unchanged founder genomes, showing body/limb/band differences.
2. **02-parents-juvenile.png:** green child #014 of teal #001 and amber #003, immediately after normal birth/control transfer.
3. **03-parents-adult.png:** same #014 and same parents after growth. Adult size 1.19 and legs 0.93 combine the parent values.
4. **04-generation-two.png:** #014 + #005 -> #015. Gen2 is visible beside both parents; the player still controls Gen1 in this capture.
5. **05-descendant-control.png:** after native family-journal selection of #015 and a scripted actual-motor sprint/turn measurement. AI/aging were temporarily frozen for inspection, hence the explicit caption and "Generations disabled" hint. This is not the permanent game's state.
